# Ivory-app

This file provides guidance to Claude Code when working in this repository.

## Status

New repository with no source code yet. Update this file with build, test, and architecture notes as the project takes shape.

## Git

- Default branch: `main`, remote `origin` (https://github.com/mberrys/Ivory-app.git).
- Make changes on a feature branch; commit only when asked.

## 6.0 plan
Under 6.0 the UI comes with the OpenResearch fork (React) and Theia is proposed to be dropped (decision 6), so this repo has no planned role yet. Do not build a separate workbench here without a decision. Candidate uses: Ivory-specific UI additions to the fork, such as the lens selector (#147) and a Pass view beside the experiment tree (experiment X5). See `docs/ivory-6.0/` in https://github.com/mberrys/Ivory.
